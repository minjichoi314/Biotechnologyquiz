# 생명기술 퀴즈 (120문항)

유전자 재조합, 핵이식, 조직배양, 세포융합 4개 단원. 각 회차에 20문항씩 출제합니다.

- 4지선다형, 난이도별 선택, 즉시 채점, 오답 복습 지원
- 문제당 네 선택지의 **문구 길이를 가급적 비슷하게 조정**해 정답 길이 편향을 개선했습니다.
- 문제/보기 큰 글씨, 캐릭터 없는 초록 칠판 UI 유지
- 외부 서버 없이 작동하는 단일 파일 `index.html`

## GitHub Pages 배포

1. GitHub에 새로운 공개 저장소를 만듭니다.
2. `index.html`을 저장소 루트에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택한 뒤 저장합니다.
4. 배포가 완료되면 GitHub Pages URL을 열어 이용합니다.

기존 점수·풀이 기록은 해당 브라우저의 저장공간에 보관됩니다. 호스팅 주소나 기기가 바뀌면 기록이 자동으로 동기화되지 않습니다.
