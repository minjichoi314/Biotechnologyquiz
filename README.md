# 생명기술 120문항 퀴즈 웹앱

유전자 재조합, 핵이식, 조직배양, 세포융합(각 30문항)을 다루는 4지선다형 웹앱입니다.

## 기능
- 한 회차에 **20문항씩** 출제하고 완료 즉시 채점합니다.
- `모든 단원 / 전체 난이도`에서는 앞서 완료한 문항을 우선 제외하므로 전체 120문항을 6회에 걸쳐 모두 풀 수 있습니다.
- 단원별 / 난이도별 선택을 지원합니다. 단원 1개 + 난이도 1개를 선택하면 해당 난이도는 10문항이므로 같은 단원의 다른 난이도 10문항을 추가하여 20문항을 구성합니다.
- O/X 모드와 캐릭터 없이 4지선다형만 제공합니다. 480개 보기 모두 각각 150자 이내입니다.
- 정답 확인, 결과 점수, 오답 재도전, CSV 오답노트, 중도 이어하기(localStorage)를 제공합니다.
- **오답 재도전**은 20개를 채우지 않고 실제로 틀린 문항만 출제합니다.

## GitHub Pages 배포
1. GitHub에서 새로운 **공개 저장소**를 생성합니다(예: `life-tech-quiz`).
2. 이 폴더의 `index.html`, `.nojekyll` 파일을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source**에서 `Deploy from a branch`를 고릅니다.
4. `main` 브랜치, `/(root)` 폴더로 설정하고 Save를 누릅니다.
5. 활성화되면 대개 `https://<계정명>.github.io/<저장소명>/`로 접속할 수 있습니다.

문항을 공개 저장소에 게시해도 되는지 먼저 확인해 주세요.
